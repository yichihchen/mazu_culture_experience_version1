# Mazu Culture Interactive Experience

A web-based interactive cultural experience inspired by Taiwan’s Mazu belief and coastal temple atmosphere.

## Tech Stack
- React + TypeScript + Vite
- Phaser 3

## Local Development
```bash
npm install
npm run dev
